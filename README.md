# SmallBiz Site Guide

Plain-English guides to websites, hosting and online tools for small business owners.

## Publishing

This is a static site served by GitHub Pages. Open **Settings → Pages**, set the source to the `main` branch and the root folder, and the site goes live at:

https://apexvaulttech-hue.github.io/smallbizsiteguide/

## Files

- `index.html` — homepage
- `about.html` — about page
- `disclosure.html` — affiliate disclosure (required on any page with affiliate links)
- `how-much-should-a-small-business-pay-for-a-website.html` — article 1

## Before publishing articles

Each article has marked `[AFFILIATE PLACEMENT]` blocks. Replace these with real affiliate links once the programs are approved. Do not publish a page with affiliate links until the disclosure page is live.
